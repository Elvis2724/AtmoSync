OVERVIEW
--------
AtmoSync is a real-time supply-chain telemetry and quantitative spoilage
arbitrage platform. It ingests high-frequency IoT container sensor streams
(temperature, relative humidity, vibration shock, CO2, ethylene, GPS), computes
dynamic Q10 / Arrhenius cargo degradation velocity, and evaluates whether
rerouting an at-risk reefer container to a closer secondary port yields higher
net cargo value ("Spoilage Arbitrage").
